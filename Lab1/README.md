## Обраний домен: Архітектура бази даних для 2D survivors-like гри

# Функціонал:
* **Прогресія гравця:** Збереження загального накопиченого досвіду та базових характеристик (здоров'я, швидкість, шкода).
* **Ігрові сесії (забіги):** Фіксація часу початку та завершення сесії, кількості пережитих хвиль та отриманого за сесію досвіду.
* **Система навичок (Skill Cards):** Зберігання характеристик здібностей та їхньої ваги (base_weight) для забезпечення механіки зваженого рандому (weighted selection) при підвищенні рівня.
* **Вороги:** Каталогізація типів супротивників із їхніми базовими параметрами (здоров'я, швидкість, шкода) та лором для подальшого спавну під час ігрової сесії.
* **Бестіарій (Статистика вбивств):** Відстеження індивідуального прогресу кожного гравця щодо знищення конкретних типів ворогів (лічильник вбивств).
