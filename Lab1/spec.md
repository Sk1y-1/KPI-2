## Сутності та атрибути

**1. Player**
* id (UUID) — унікальний ідентифікатор гравця (PK).
* username (string) — ім'я користувача.
* total_experience (number) — загальний накопичений досвід (мета-прогресія).
* health (number) — базове здоров'я.
* movespeed (number) — базова швидкість руху.
* damage (number) — базова шкода.
* attack_speed (number) - швидкість атаки зброї.

**2. Game_Session**
* id (UUID) — унікальний ідентифікатор сесії (PK).
* player_id (UUID) — посилання на гравця (FK).
* start (datetime) — час початку забігу.
* end (datetime) — час завершення забігу.
* earned_experience (number) — досвід, отриманий за поточну сесію.
* waves_survived (number) — кількість пережитих хвиль.

**3. Skill_Card**
* id (UUID) — унікальний ідентифікатор навички (PK).
* name (string) — назва навички.
* base_weight (number) — вага для системи рандомізованого вибору здібностей (weighted skill selection).
* damage (number) — показник шкоди.
* type_damage (string) — тип шкоди.
* describe_ability (string) — текстовий опис здібності.
* cooldown (number) — час перезарядки.

**4. Enemy**
* id (UUID) — унікальний ідентифікатор типу ворога (PK).
* name (string) — назва.
* base_health (number) — базове здоров'я (використовується для розрахунку поведінки штучного інтелекту).
* movespeed (number) — швидкість руху.
* damage (number) - показник шкоди яку наносить ворог.
* type (string) — тип ворога.
* describe_enemy (string) — опис ворога або лор.

**5. Bestiary** 
* id (UUID) — унікальний ідентифікатор запису бестіарію (PK).
* player_id (UUID) — посилання на гравця (FK).
* enemy_id (UUID) — посилання на тип ворога (FK).
* counter (number) - підрахунок кількості вбитих мобів гравцем. Додаток для кожної унікальної пари (player_id, enemy_id) існує лише один запис.
  
## Опис зв'язків
* **Player 1:N Game_Session ("has", `||--o{`)**
* **Player M:N Skill_Card ("starts_with", `}o--o{`)**
* **Game_Session M:N Skill_Card ("unlocks", `}o--o{`)**
* **Game_Session M:N Enemy ("spawns", `}o--o{`)**
* **Player 1:N Bestiary ("tracks_kills", `||--o{`)**
* **Enemy 1:N Bestiary ("references", `||--o{`)**: Кожен тип ворога може фігурувати в багатьох записах бестіарію (по одному на кожного гравця), а кожен запис бестіарію посилається рівно на один тип ворога.

## Критерії прийняття
1. Модель відповідає 3-й нормальній формі (3NF).
2. Первинні та зовнішні ключі типізовані як UUID.
3. Усі зв'язки «багато-до-багатьох» реалізовані як чисті асоціації без фізичних сполучних таблиць, окрім випадків, коли асоціативна сутність несе власні атрибути (як у випадку з Bestiary, де зберігається counter).
4. Назви атрибутів у специфікації повністю узгоджуються з діаграмою.
